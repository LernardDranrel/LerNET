# LerNET v1.1.0

## Экспертный режим для Android и Windows

- Постоянный TUN с общей схемой маршрутизации устройства. Новая схема по умолчанию направляет трафик напрямую; включение выполняется пользователем.
- Правила для приложений, доменов, IP и стран, явные ветки «ИНАЧЕ», блокировка и перенаправление трафика.
- Выходы через профили, папки и общие каналы; выбор сервера и автосмена внутри папки, холодный старт и отключение простаивающих подключений.
- История соединений, сведения о приложении и назначении, объём и скорость трафика, причины отказов, отдельные списки коротких и длительных соединений с режимом Live.
- Симулятор пути из истории соединений или ручного примера с отображением маршрута на схеме.

## Надёжность и удобство

- Доработаны обработка потери и восстановления сети, состояние постоянного туннеля и восстановление обычного VPN.
- Expert сохраняет системный DNS по умолчанию; другой DNS задаётся явно. Уточнены обработка IPv4/IPv6 и выбор прямого маршрута вне собственного TUN.
- Переработаны редактор схемы, масштабирование и перемещение на Android, действия внутри блоков и меню экспертного режима. Настройки приложения, профили и диагностика остаются доступны.
- Рубильник показывает запуск, работу и ошибку отдельно; поддерживает нажатие и перетаскивание.
- Уточнены запрет прямого выхода для всей ветки, его наследование и поведение при отказе. Конфликты в дочерних деревьях указывают проблемное правило; можно явно использовать выбранный VPN/прокси без его дерева.
- Улучшены диагностика Windows и сообщения установщика при подготовке обновления.

## Скачать и обновить

- **LerNET-1.1.0.apk** — Android 8.0 и новее, ARM64, build 119. Подпись приложения сохранена; устанавливается поверх предыдущей версии.
- **LerNET-1.1.0-install.exe** — установщик Windows x64.
- **LerNET-1.1.0-portable.zip** — Windows без установки. Распакуйте целиком, сохранив рядом EXE, `app` и `runtime`.
- **LerNET-1.1.0-SHA256SUMS.txt** — контрольные суммы трёх пакетов.

Перед заменой Windows-файлов завершите LerNET через «Выход» в трее. При обновлении работающее VPN-соединение временно прекращается. Профили и настройки приложения сохраняются.

## Проверки и ограничения

В финальном наборе проверок прошли **634 теста логики**: 604 для Android и общих модулей, 30 для Windows. Обе платформы собраны; Android lint — без ошибок, подпись APK и выравнивание нативных библиотек для страниц 16 КБ проверены. Файлы portable-архива сверены с собранным Windows-приложением.

Финальная проверка выполнена без виртуальных машин и эмуляторов. Последняя сборка не проходила полный приёмочный прогон на физических устройствах и проверку установки поверх всех прежних вариантов установки.

TUN не расшифровывает HTTPS/TLS/QUIC. История показывает доступные метаданные и передачи, а не содержимое зашифрованных запросов. Симулятор рассчитывает маршрут локально и не подтверждает доступность сервера. На Android системные режимы Always-on VPN и блокировки соединений без VPN настраиваются отдельно в ОС.
