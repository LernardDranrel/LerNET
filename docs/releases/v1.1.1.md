# LerNET 1.1.1 — Android, build 120

## Исправления

- HTTPS-проверка выходов Expert использует хранилище доверенных сертификатов и источник времени нативного ядра, в том числе на Android. Проверка сертификатов остаётся включённой.
- Ошибки сертификата, DNS и HTTP-ответа проверочного сервера больше не вызывают перезапуск выхода с обрывом его соединений. Неудачная проверка остаётся видимой и не считается успешной.
- Отдельные сообщения для ошибок сертификата, разрешения имени и тайм-аута вместо общего `https_probe_failed`.
- В экспорт журнала добавлены состояния выходов, коды причин отказа, доступность исходной сети и количество выбранных выходов папок. Повторяющиеся опросы не засоряют журнал; новые диагностические строки не содержат адресов сайтов, содержимого трафика или секретов профилей.

## Скачать

`LerNET-1.1.1-android-120.apk` — Android 8.0+, ARM64. Можно установить поверх текущей версии: подпись приложения сохранена. Контрольная сумма — в `SHA256SUMS.txt`.

Этот выпуск содержит Android-обновление. Windows-пакеты доступны в [релизе 1.1.0](https://github.com/LernardDranrel/LerNET/releases/tag/v1.1.0).

## Проверки и ограничения

Прошли 58 тестов нативного Expert и 82 JVM-теста. Android release собран, lint — без ошибок; проверены подпись APK, включение обновлённого ядра и выравнивание библиотек для страниц 16 КБ.

Полный приёмочный прогон этой сборки на телефоне ещё не выполнен. Исправлены подтверждённые ошибки кода; устранение всех наблюдавшихся сбоев доступа к сайтам пока не подтверждено. При повторении ошибки экспортируйте журнал сразу после сбоя.

Для воспроизводимой сборки из исходников используется `:app:assembleRelease -PlernetVersion=1.1.1`.
