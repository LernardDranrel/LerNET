# LerNET v1.1.0 — HTML-макеты

Откройте `index.html` в браузере. Установка и сборка не нужны; стили, скрипты и значки локальные. Каталог содержит **42 экрана для Windows и Android**, варианты состояний и переходы.

## Как смотреть

1. Выберите экран слева и платформу сверху.
2. Переключите состояние: пусто, отказ, сон/пробуждение, черновик, нет разрешения и другие варианты.
3. Нажимайте кнопки, открывайте меню, проверяйте формы. Escape закрывает диалог, Enter подтверждает.
4. В схеме удерживайте блок около 340 мс и перетаскивайте. Призрак следует за указателем. Для управления с клавиатуры есть список и редактор правила.
5. В Android редакторе нижняя панель применяет черновик; схема показывает выбранный путь без миниатюрного текста всей сети.

Отдельно можно открыть `windows.html` и `android.html`. В HTML есть якоря, например `windows.html#schema` или `android.html#expert?state=waking`. В рамках каталога навигация внутри приложения также обновляет выбранный экран.

## План

- `plan.html` — читаемый план с оглавлением и стилями печати.
- Основной документ для реализации: `docs/plans/v1.1.0-network-manager.md` в репозитории (в архиве также приложен как `implementation-plan.md`).
- Состояние поставки: макеты и план; сетевой движок версии 1.1.0 ещё не реализован.

## Границы макета

Все значения — демонстрационные. Системные разрешения, сканирование QR, проверки сервера, внешний IP, установка обновления и состояние сети показываются примерами. Файл импорта можно прочитать локально; его реальный контракт не проверяется этим макетом. Прототип не запускает файлы, не отправляет сетевые запросы и не меняет настройки устройства.

Сохраняемый из макета отчёт содержит маркер `demo: true`. Его нельзя использовать для диагностики настоящей сети. Настройки и изменения существуют только в текущем окне макета.

## Проверка

`evidence/verification.json` — журнал отрисовки экранов и проверки взаимодействий. Снимки важных страниц лежат в `evidence/`.

Проверено: обе платформы, ширины 1440 / 390 / 360, состояния, формы, диалоги Enter/Escape, геометрия призрака, отсутствие внешних зависимостей. Полноценная проверка TalkBack/Narrator, расхода батареи, сетевых гарантий и производительности будущего Compose-приложения выполняется при реализации.

`verify.cjs` предназначен для разработчика с Playwright. Он проверяет только HTML и не запускает LerNET/VPN. В текущей рабочей среде браузер запускается с отдельным временным профилем; рабочие браузерные профили не используются.
