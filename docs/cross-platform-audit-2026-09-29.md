# Ревизия контрактов Android и Windows

Дата: 29 сентября 2026. База: v1.0.8 и текущие правки совместимости веток.

Проверялась последовательность **экспорт → импорт → хранение → редактирование → компиляция → выбор режима → переподключение**. Критерий: перенос сохраняет исходные данные и смысл правил; ограничения устройства исключают целую ветку; проверка читает те же условия, что и ядро; смена профиля сохраняет параметры сессии.

Приложение, настоящий sing-box и VPN на ноутбуке не запускались. Контроллер Windows проверялся с временным хранилищем, без подключения; ошибочный запуск дополнительно ограничен несуществующим путём ядра. Контроллер Android проверялся с подставным `BoxEngine` и подставным сетевым вызовом.

Для переноса сохранены формат `lernet-transfer` и версия схемы 1. Валидные существующие архивы остаются совместимыми. Неизвестные значения режима и источника DNS отклоняются явно, вместо различной молчаливой подстановки на разных платформах.

## Согласованное поведение, проверенное по реализации

- Маршрутом профиля внутри папки владеет папка на обеих платформах.
- Несовместимое условие Android/Windows выключает всю ветку с потомками. Сохранённое `enabled` и сами условия остаются переносимыми.
- И/ИЛИ старого формата при импорте на Android записывается в блоки; существующие блоки сохраняются.
- Приоритет правил определяется порядком дерева, а не координатами схемы.
- Один и тот же непустой `pipeName` после обрезания внешних пробелов обозначает один канал. Разные имена с одинаковым техническим slug получают разные теги.

## Оставшееся расхождение настроек

Политика DNS `SYSTEM` на Windows означает наследование общей настройки при каждом подключении. Android при импорте заменяет её текущей настройкой по умолчанию и сохраняет конкретное значение `UNDERLAY`/`PROFILE`. Поэтому последующая смена общей политики влияет на такой Windows-профиль, но не на импортированную Android-копию. Это отдельное расхождение модели наследования; в этой ревизии оно не менялось. Для унификации нужно сохранить наследуемое значение в Android-модели и показать его в редакторе профиля и общих настройках.

## Границы проверки

Ревизия не подтверждает работу установщика на другом компьютере, фактическое получение UAC/VpnService-разрешения, маршруты ОС при одновременно работающем стороннем VPN и сетевой авто-свап на настоящем устройстве. Эти случаи требуют проверки на устройстве. Отсутствие ошибки в проверке HTTP через профиль по-прежнему не является подтверждением правильного маршрута всего устройства через TUN.
