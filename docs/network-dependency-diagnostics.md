# Разбор зависимости от другого VPN

## Как снять полный разбор

1. Открыть «Сеть устройства», оставив другой VPN включённым. Дождаться завершения сбора.
2. В «Что изменилось» нажать «Зафиксировать текущий снимок «до»».
3. Когда безопасно прервать сеть, штатно отключить другой VPN. Не закрывать окно наблюдения.
4. Нажать «Обновить» и дождаться окончания. Закреплённый снимок не заменяется.
5. При необходимости выполнить проверку связи профиля LerNET. Ошибки сохраняются в журнале.
6. Нажать «Сохранить полный разбор». Один JSON содержит текущий снимок, baseline, changes, diagnosticLog и время чтения журнала diagnosticLogCapturedAt.

Безопаснее сохранить файл и до отключения VPN. Снимок не является атомарным: capturedAt каждого источника помогает сопоставить момент чтения. Запись TCP/IP остаётся отдельным действием пользователя; снимок её автоматически не запускает.

## Что означают предупреждения

- **Локальный DNS:** 127.0.0.1/::1 требует программы на устройстве. Отсутствие TCP/UDP-порта 53 отмечается как возможная проблема только при полном чтении обеих таблиц. Перехват DNS фильтрами Windows остаётся возможен.
- **Внешний виртуальный путь:** расчёт по снимку показывает путь к числовому адресу сервера. Совпадение названия адаптера с процессом/службой — подсказка, не доказательство владения.
- **Предупреждение перед подключением:** Windows IP Helper читает интерфейс для числового адреса, а Java получает описание драйвера. Предположение о туннеле основано на описании. Это обычный маршрут Windows, а не гарантированный путь сокета, привязанного приложением к другому интерфейсу.
- **503 проверки:** код локального delay API sing-box. Он не доказывает HTTP-ответ сайта. После ошибки может выполняться один HTTP-запрос через тот же временный прокси; напрямую он не повторяется. Лимит общей проверки сохраняется, успешный ответ второго запроса не превращает первый отказ в успех.
- **Частичный WFP:** при повреждении поздней части XML сохраняются полностью прочитанные фильтры. Удалённые/непрочитанные условия нельзя считать отсутствующими. DTD и внешние сущности запрещены; XML ограничен 32 МБ.
- **Брандмауэр:** метаданные правил и три коллекции условий читаются отдельно из ActiveStore. Ошибка одной коллекции не удаляет остальные. InstanceID позволяет исследовать записи; одна совпавшая строка не доказывает срабатывание правила.

Сборщик не останавливает чужие VPN, не меняет DNS, маршруты, фильтры или правила брандмауэра. Полный разбор сохраняется локально; сетевой запрос проверки использует настроенный адрес проверки и выбранный профиль.
