В экспертном режиме Windows появились именованные шаблоны. У каждого шаблона своя сохранённая схема и свой черновик. Пульт показывает, какой шаблон действует сейчас. Другой шаблон можно открыть для редактирования во время подключения.

Для Windows доступны установщик и портативная версия в ZIP. Контрольные суммы файлов указаны в `SHA256SUMS-1.1.9.txt`.
