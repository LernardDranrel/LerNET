## Что изменилось

- Android: на главном экране теперь отдельно измеряется время ответа сервера по TCP и HTTPS-запрос через выбранный профиль. Проверка через туннель доступна после подключения и запускается также кнопкой «Проверить связь».
- Windows: функциональность не менялась; версия приложения обновлена до 1.0.2 вместе с общим проектом.

В релиз входят подписанный APK для Android, EXE установщик и портативный ZIP для Windows. Контрольные суммы файлов приведены в `SHA256SUMS.txt`.
