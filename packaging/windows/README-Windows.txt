LerNET для Windows — портативная версия

1. Распакуйте весь архив LerNET-*-portable.zip.
2. Откройте папку LerNET и запустите LerNET.exe.
3. Для полного VPN подтвердите запрос прав администратора. Если запрос отменён, приложение откроется с локальным прокси.

Не переносите один LerNET.exe отдельно от папок app и runtime: в архиве находится встроенная Java и сетевое ядро.

Установочная версия распространяется отдельным файлом LerNET-*-install.exe.
Профили, правила и журнал сохраняются в %APPDATA%\LerNET.

Если установщик показывает Repair / Change / Delete, Windows уже считает эту версию LerNET установленной. Запустите приложение через меню «Пуск» или ярлык. Для повторной установки той же версии сначала удалите LerNET через «Установленные приложения»; профили в %APPDATA%\LerNET останутся на месте.
