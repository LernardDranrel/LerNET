LerNET для Windows — портативная версия

1. Распакуйте весь архив LerNET-*-portable.zip.
2. Откройте папку LerNET и запустите LerNET.exe.
3. Для полного VPN подтвердите запрос прав администратора. Если запрос отменён, приложение откроется с локальным прокси.

Не переносите один LerNET.exe отдельно от папок app и runtime: в архиве находится встроенная Java и сетевое ядро.

Установочная версия распространяется отдельным файлом LerNET-*-install.exe.
Профили, правила и журнал сохраняются в %APPDATA%\LerNET.

Обновление установленной версии: откройте новый LerNET-*-install.exe. Мастер покажет найденную версию, остановит установленную копию и обновит файлы. При этом VPN временно отключится. На последнем экране галочка «Запустить LerNET» включена по умолчанию.
Старый установщик MSI удаляется автоматически перед установкой новой версии; пользовательские данные остаются на месте.
Портативную копию закройте через меню «Выход» в трее и распакуйте новый ZIP в её папку.
В настройках приложения можно проверить обновления с GitHub.

Экспертный режим включается отдельно и требует прав администратора. Он направляет
трафик через постоянный TUN; без совпавшего правила соединения идут напрямую.
Сохранение схемы и применение к действующей сети — разные действия.

Дополнительная системная защита Windows блокирует выход вне LerNET и сохраняет
запрет после остановки TUN или сбоя приложения. Чтобы вернуть обычную сеть,
отключите защиту отдельно в разделе «Эксперт → Защита». Восстановление удаляет
только собственные ограничения LerNET; настройки других VPN не удаляются.
