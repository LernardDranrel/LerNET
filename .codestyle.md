# LerNet code style

This file is the project style source of truth. Tools (Spotless/ktlint, detekt, Android Lint) enforce a subset; humans and agents follow the rest.

## Language and UI

- Source identifiers, comments, and commit messages: English.
- User-facing strings: Russian, via `strings.xml` / `stringResource`. Do not hardcode English UX labels.
- Stay consistent: do not mix Russian and English in the same user-visible surface.

## Kotlin

- Official Kotlin style, 4-space indent, UTF-8, LF.
- Max line length 140 (`.editorconfig`).
- Imports only at the top of the file. No inline imports in function bodies, types, or interfaces unless a documented circular-dependency exception exists.
- `when` on sealed types and enums must be exhaustive. Use a `else ->` branch that assigns to `Nothing` / `error` only for truly impossible cases; prefer a `never` helper so new variants fail at compile time.
- No empty `catch`. Engine and VPN paths must either recover with a typed `ConnectionCause` or rethrow. Logging a swallow is not recovery.
- Prefer small types with one job. No god `*Manager` / `*Helper` classes.
- ViewModels are unidirectional: `UiState` + `Intent` + one-shot `Event`. Do not expose mutable UI state.

## Modules

| Module | May depend on |
|--------|----------------|
| `core-ui` | AndroidX Compose / Material 3 only |
| `core-config` | Kotlin stdlib, serialization, Room, OkHttp |
| `core-routing` | Kotlin stdlib, serialization (`core-config` domain types only if needed) |
| `core-engine` | `core-config`, `core-routing` |
| `app` | all of the above |

Do not invert this graph. Do not put Compose in `core-engine` or Room in `core-routing`.

## Secrets and logs

- Never write UUID, password, private key, `pbk`, `sid`, or raw share links at info/debug without redaction.
- Use `SecretRedactor` before any log sink.
- Generated sing-box JSON may contain secrets in memory and on private app storage only.

## Tests

- Parsers, `RouteCompiler`, reconnect/failover machines: pure unit tests, no Android runtime.
- Fake clocks / test dispatchers for time. Do not `delay` against wall clock.
- Name tests after the spec rule they protect (`exact domain beats app`).

## Formatting

- Spotless + ktlint (`com.pinterest.ktlint`) is the formatter. Run `./gradlew spotlessApply` before commit if you did not use the IDE formatter.
- detekt config lives in `config/detekt/detekt.yml`. Do not disable `EmptyCatchBlock`.
